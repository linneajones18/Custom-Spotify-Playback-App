# Custom Spotify Playback Web App using React
The purpose of this project is to build a custom Spotify playback page to give a 2011 Mac a use. The app will need to be able to run on the 2011 Mac. That way the old Mac will have a use other than trash - as an aesthetic Spotify display when music is playing in the room.

To set up the Spotify Web Player functionality, I referenced Spotify for Developers' [Building a Spotify Player inside a Web app
](https://developer.spotify.com/documentation/web-playback-sdk/howtos/web-app-player) documentation.
